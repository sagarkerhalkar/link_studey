# Project Resource Policy

This policy is mandatory for all future Link Analytics work.

1. The project resource package is the canonical source of truth.
2. Every code change must be written into the source tree included in the package.
3. Every issue must be appended to `PROJECT_ISSUE_LOG.md`.
4. Every action and diagnostic must be appended to `PROJECT_ACTIVITY_LOG.md`.
5. Every requirement must remain traceable in `REQUIREMENT_TRACEABILITY.md`.
6. Every release must include raw test outputs, screenshots and test reports under `test-results/`.
7. Every deployment change must be documented in README and deployment documents.
8. The canonical current package must be replaced with the latest complete code package after each build.
9. Previous history must not be deleted; it remains in changelogs and logs.
10. A physical-device/platform claim cannot be marked complete using only simulated headers or desktop emulation.
