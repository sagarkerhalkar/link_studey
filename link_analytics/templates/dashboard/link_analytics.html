Tracking method and data integrityOpen technical details

One unchanged short URL: platform detection uses real request evidence only. Confirmed means direct package, in-app signature or referrer evidence. Probable means an identifiable app preview immediately preceded a hidden browser launch.

Device calculation: version 4.2 separates browser/app identities from estimated physical devices. Cross-context merging needs multiple matching hardware signals and a salted network scope.

Excluded traffic: {{ analytics.preview_requests }} preview/bot requests and {{ analytics.unverified_requests }} incomplete requests are not included in clicks, devices or repeat calculations.

Historical records are separated: Shlink {{ analytics.legacy.shlink_total }}, local v2 {{ analytics.legacy.local_v2_events }}, local v3 {{ analytics.legacy.local_v3_events }}. These records remain outside current charts.
